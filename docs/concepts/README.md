# Concepts — the two-game split

A 2026-06-06 brainstorm established that "Politiko" was straining to be **two different games at
once**. We split them so each can be itself, and **prioritized one to build**:

| Concept | Protagonist | Main UI | Status |
|---------|-------------|---------|--------|
| [**Statesman**](statesman.md) (Game 1) | the **nation** | **map** | **PRIORITY — in development** |
| [**Trapo**](trapo.md) (Game 2) | the **family** | **menus** | Captured, **parked** |

**The hard rule:** separate the *concepts*, build *one*. We prioritize **Statesman** because it builds
directly on the engine + 3D map already in the repo. **Trapo** is captured here so it's safe — it is the
*menu/tycoon* game (corrupt-contractor dynasty, FAFO) and shares Statesman's domain; in fact Statesman is
Trapo's eventual endgame. Neither is wasted on the other.

The settled decisions in [`../REVIEW-TRACKER.md`](../REVIEW-TRACKER.md) (open-ended, no game-over, etc.)
belong to **Statesman**. Trapo's "game-over is personal" failure model is its own thing and does **not**
apply to Statesman.
